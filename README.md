# BHX-Brain-Hemorrhage-Analysis
Exploratory analysis of the BHX (Brain Hemorrhage Extended) dataset using shell scripting and biomedical imaging metadata


## Overview

This project explores the Brain Hemorrhage Extended (BHX) dataset, a biomedical imaging dataset containing CT scan annotations and hemorrhage bounding boxes.

The analysis focuses on extracting, filtering, and summarizing medical imaging information using shell scripting tools and dataset metadata.

## Dataset

Brain Hemorrhage Extended (BHX)

The dataset contains:

* CT scan image metadata
* Hemorrhage annotations
* Bounding box coordinates
* Manual and extrapolated labels

## Objectives

* Explore the structure of the dataset
* Analyze annotation records
* Identify hemorrhage categories
* Extract subdural hemorrhage cases
* Generate summary statistics from biomedical metadata

## Tools Used

* Google Colab
* Linux Shell Commands
* Bash
* CSV Processing Utilities

Main commands used:

* grep
* cut
* sort
* uniq
* wc
* head
